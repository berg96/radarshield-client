# Бриф дизайнеру — «продвинутые» экраны в НАШЕМ стиле (RadarShield)

**Контекст.** Первый макет (один экран-кнопка) — отличный, утверждён. В нём
«продвинутый режим» был заглушкой, открывающей родной интерфейс FLClash. **Решение
изменилось: чужой интерфейс не показываем вообще.** Всё, что может понадобиться
пользователю, должно быть нарисовано в нашем стиле (та же тёмная navy-тема, янтарь,
шрифты Inter/Manrope, компоненты из первого макета).

Этот бриф = что именно нужно дорисовать. Ниже — что у «обычного» VPN-движка
(FLClash/clash) вообще есть, и решение по каждому: **рисуем своё / упрощаем /
выкидываем**. Дизайнить нужно только пункты «рисуем».

---

## Что мы за продукт (рамка для решений)
Управляемый потребительский VPN: **одна подписка на пользователя**, выдаётся нашим
Telegram-ботом; маршрутизация (обход РФ-сайтов напрямую, остальное — через VPN)
**вшита нами**, пользователь её не настраивает. Аудитория — неискушённый юзер.
Поэтому всё «конфиговое/раздача правил/несколько подписок» — не нужно.

---

## ✅ РИСУЕМ (наши экраны вместо FLClash)

### 1. Выбор локации / сервера  ⭐ главный «продвинутый» экран
Сейчас на главной есть чип «Россия · авто». По тапу — этот экран.
- Список локаций (у нас сейчас ~4 ноды: Германия, Нидерланды, Финляндия, США —
  позже больше). Для каждой: флаг/страна·город, **пинг (мс)** живой, индикатор
  загрузки/качества, радиокнопка выбора.
- Сверху — пункт **«Авто (лучший сервер)»** (выбран по умолчанию, подбираем по пингу).
- Текущая выбранная — подсвечена зелёным (как в прототипе `AdvancedStub`).
- Кнопка «Проверить пинги» (refresh).
- Состояния: загрузка пингов, нода недоступна (серый), выбранная.

### 2. Детали соединения (карточка/шторка с главного экрана)
Когда подключено — по тапу на статус/«i» открыть детали:
- Текущий сервер, **ваш видимый IP**, протокол (можно просто «защищённый»),
  время сессии, трафик ↑/↓ за сессию.
- Кнопка «Сменить сервер» (→ экран 1).

### 3. Диагностика / журнал (для поддержки)
Вместо сырых clash-логов — дружелюбный экран:
- Статус последнего подключения, короткий журнал событий (подключился/отключился/
  ошибка), версия приложения, ID устройства.
- Большая кнопка **«Скопировать для поддержки»** / «Отправить в Telegram-бот».
- Тон — не технический.

### 4. Раздельный туннель (split tunneling, Android)
Какие приложения пускать мимо VPN / только через VPN. Реальная нужная фича.
- Список установленных приложений с иконками + переключатель на каждое.
- Режим: «все через VPN, кроме выбранных» / «только выбранные через VPN».
- Поиск по списку. (На Windows — позже или скрыть.)

### 5. Экран настроек — расширить уже утверждённый
К уже нарисованным (аккаунт, продвинутый режим→теперь на экраны выше, локация,
автоподключение, язык, о приложении) добавить простые тумблеры:
- **Kill-switch** — «Блокировать интернет, если VPN отключился».
- **Уведомление о статусе** — постоянная нотификация (Android требует для VPN).
- **Тема** — если хотим (тёмная/светлая/системная). Можно зафиксировать тёмную и не давать выбор.
Каждое — одной строкой-тумблером, без подэкранов конфигов.

---

## 🟡 УПРОЩАЕМ (есть в движке, но прячем за простой вид)
- **Автоподключение / TUN / системный прокси** → один тумблер «Автоподключение» (уже в макете) + kill-switch. Никаких портов/стеков.
- **Тема / язык** → простые строки (уже учтено).

## ❌ ВЫКИДЫВАЕМ (движок умеет, нам не нужно — НЕ рисовать)
- **Профили / несколько подписок / импорт / автообновление профиля** — у нас одна управляемая подписка (онбординг + карточка аккаунта это закрывают).
- **Редактор правил маршрутизации** (DOMAIN/IP-CIDR/GEOSITE и т.п.) — маршруты вшиты нами.
- **Базовый/продвинутый конфиг** (DNS, порты, TUN-стек, mixed-port, sniffer) — управляем сами.
- **Группы прокси** в общем виде — сводим к «Выбору локации» (экран 1).
- **Ресурсы / гео-базы** — обновляем автоматически в фоне.
- **Сырые «запросы»/connections-таблица** — заменяем «Деталями соединения» + «Диагностикой».
- **Бэкап/восстановление, хоткеи, loopback** — нишевое десктопное, не для потребителя.

## Навигация (как это собрать вместе)
Главная (кнопка) остаётся центром. Точки входа в «наше продвинутое»:
- чип «Локация» на главной → **экран 1** (выбор сервера);
- «i»/статус на главной → **детали соединения** (экран 2);
- шестерёнка → **Настройки**, а из них: «Раздельный туннель» (экран 4),
  «Диагностика» (экран 3), тумблеры (экран 5).

Никакой кнопки/перехода «FLClash» — её убираем полностью.

## Стиль
Строго как в первом макете: navy `#0d1b2a`, панели `#12243a`, янтарь `#ffb703`,
зелёный «подключено» `#2fc98a`, текст `#eef3f9`/`#b7c4d3`/`#7f8fa3`, скругления
12–16, Inter/Manrope. Компоненты (карточки, строки-тумблеры, чипы) переиспользовать
из `design/prototype/screens.jsx`.
